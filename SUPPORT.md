# Support

Use [GitHub Discussions](https://github.com/reinventinglikes/relikes/discussions) for integration and protocol questions. Use issues for reproducible bugs. Include the Re:Likes and Clean Selection versions, browser, backend type, configuration, response status and error code, and a reduced reproduction with secrets removed.

Security reports belong in [private vulnerability reporting](SECURITY.md).
